## How to Populate This Report

Run the validation suite to auto-generate a filled version of this report:

```bash
cd validation/
python run_validation.py --mode seed
```

For live database comparison:

```bash
python run_validation.py --mode live \
    --legacy-conn "mssql+pyodbc://user:pass@server/DWH?driver=ODBC+Driver+17+for+SQL+Server" \
    --databricks-host "your-workspace.cloud.databricks.com" \
    --databricks-token "your-token" \
    --databricks-catalog "your_catalog"
```

Output files will be generated in `validation/output/`.
